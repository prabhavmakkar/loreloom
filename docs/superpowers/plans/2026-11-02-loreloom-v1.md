# Loreloom v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local, open-source novel-writing app with chapters, page counts, a world library, a character map and an AI helper (Brainstorm, Draft, Review). The helper runs on the writer's own Claude Code login, and an MCP server exposes the same book.

**Architecture:** An npm-workspaces TypeScript monorepo with four packages.

- `core` owns the plain-Markdown book folder (reading, writing, stats, AI context).
- `server` is a Hono app on 127.0.0.1. It serves the API and the built UI, and spawns the user's unmodified `claude` CLI in headless stream-json mode.
- `web` is a Vite + React UI (TipTap editor, Cytoscape map).
- `mcp` is a stdio MCP server over `core`.

**Tech Stack:**
- Node 22, TypeScript (strict), npm workspaces, Vitest (+ jsdom for web logic)
- Hono + @hono/node-server, chokidar 4, `yaml`
- React 19 + Vite, TipTap (with Mention and a Markdown extension), Cytoscape.js, dnd-kit
- @modelcontextprotocol/sdk + zod
- tsx, used to run server and mcp without a build step

**Spec:** `docs/superpowers/specs/2026-11-02-loreloom-design.md`. Read it first. Section numbers below (§) refer to it.

## Global Constraints

**Repository and runtime**
- Repo root is `Fantasy Novel/loreloom/`. The author's book lives at `Fantasy Novel/book/`, **outside** the repo. Never put manuscript files in the repo except the sample book.
- Node 22+ only. No pnpm or yarn (npm workspaces). Use the latest stable versions, pinned exactly in package.json.
- The server binds `127.0.0.1` only. The default port is `4317`; if it's taken, try up to `4327`.

**Claude credentials**
- Never read, store, copy or forward Claude credentials or anything under `~/.claude`.
- Auth state comes only from `claude auth status --json`, and only the `loggedIn` and `subscriptionType` fields are read.
- Never modify or bundle the `claude` binary. Spawn whatever `claude` is on PATH.

**Naming**
- "Claude" and "Anthropic" never appear in the product name, logo or package names.
- Copy may say "runs Claude Code".

**The author's text**
- The AI never writes into a chapter. Only an explicit user click on Insert, Replace or Apply changes chapter text.
- Book format (§7.2): `book.yaml` and `chapters/<id>.md`, plus world cards in `world/characters/`, `world/places/`, `world/rules/` and `world/glossary/`. App state goes in `.loreloom/`.
- *Builder's call:* chapter filenames are `<id>.md`, with order in frontmatter instead of an `NN-` prefix, so reordering never renames files.
- Mention syntax in Markdown: `[Label](@<kind>/<id>)`, where kind ∈ `character|place|rule|term`.
- Pages = `Math.ceil(words / wordsPerPage)`, with `wordsPerPage` defaulting to `250`. Zero words is zero pages.

**Saving**
- All file writes are atomic (temporary file, then rename) through `writeFileAtomic`.
- Deleting a chapter or card moves the file to `.loreloom/trash/<timestamp>-<name>`. Nothing is unlinked.
- Save status copy is exactly `Saving…`, `Saved · just now` (or `Saved · N min ago`), `Not saved: retry` and `Changed elsewhere`.

**Helper copy**
- Not logged in: `Open a terminal and run \`claude\`, then \`/login\`.`
- Not installed: `Loreloom's helper runs on Claude Code. Install it from https://code.claude.com, then reload.`

## Review Focus

1. **A chapter is edited outside the app** (another editor, or Claude via MCP) while it's open with unsaved edits. Expect the `Changed elsewhere` banner offering *Load theirs / Keep mine*, never a silent overwrite either way. Tests are in Task 2 (`ConflictError`), Task 5 (watcher event + 409) and Task 8 (save queue → conflict state).
2. **The disk write fails or the server is down while typing.** Expect status `Not saved: retry` and the text kept in localStorage, which restores the draft after a reload. A `beforeunload` prompt appears while unsaved. Tests are in Task 8.
3. **Some other website the user visits calls `http://127.0.0.1:4317/api/...`** (CSRF or DNS rebinding). Expect a 403. It must never be able to read or write the book or run the helper. Tests are in Task 4.
4. **`claude` is missing, logged out, hits the subscription usage limit mid-reply, crashes, or the user hits Cancel.** Expect a clear message in the panel. There should be no hung spinner and no orphaned process. Tests are in Task 6.
5. **Odd titles and ids**: emoji or non-Latin titles, duplicate titles, `../` or `/` in API ids. Expect safe unique slugs and a 400 for invalid ids, with no path traversal. Tests are in Task 1 (slugify), Task 2 (InvalidIdError) and Task 4 (400 response).

### Task 4: server API + localhost guard

**Files:**
- Create: `packages/server/package.json` (name `@loreloom/server`), `packages/server/src/{app,guard,cli}.ts`
- Test: `packages/server/test/{api,guard}.test.ts`

**Interfaces:**
- Consumes: `Book`, `bookStats`, the errors.
- Produces `createApp(opts: { bookDir: string; sampleDir: string; provider: AiProvider; staticDir?: string }): { app: Hono; getBook(): Book|null }`. `AiProvider` is a type-only import from Task 6. Until then, use a stub with `status()` returning `{available:false, reason:'not_installed'}`.
- All JSON routes are under `/api` and require the header `X-Loreloom: 1`:

  | Route | Behaviour |
  |---|---|
  | `GET /api/book` | `{exists:false}` or `{exists:true, meta}` |
  | `POST /api/book` | `{title, author}` or `{sample:true}`. Returns 201 `{meta}`; 409 if one exists |
  | `PATCH /api/book` | updates `meta` |
  | `GET /api/stats` | `BookStats` |
  | `GET /api/chapters` | `Chapter[]` without `body` |
  | `POST /api/chapters` | `{title}` |
  | `PUT /api/chapters/order` | `{ids}` |
  | `GET /api/chapters/:id` | the chapter |
  | `PUT /api/chapters/:id` | `{patch, baseVersion?}` |
  | `DELETE /api/chapters/:id` | |
  | `GET /api/cards?kind=` | |
  | `POST /api/cards/:kind` | |
  | `GET\|PUT\|DELETE /api/cards/:kind/:id` | `PUT` takes `{patch, baseVersion?}` |
  | `POST /api/cards/character/:id/relationships` | add |
  | `DELETE /api/cards/character/:id/relationships` | remove; body `{to, kind}` |

- Error mapping: `NotFoundError`→404, `ConflictError`→409 `{error:'conflict', current}`, `InvalidIdError`/`InvalidInputError`→400, `NotABookError`→409 `{error:'no_book'}`. An unknown card kind is a 400.
- When `staticDir` is set, non-`/api` GETs serve the files, with SPA fallback to `index.html`.
- `guard.ts` exports `localGuard(): MiddlewareHandler`. It rejects with 403 when:
  - the `Host` hostname isn't `127.0.0.1` or `localhost`;
  - an `Origin` is present and its hostname isn't one of those;
  - an `/api` request (other than `GET /api/events`) lacks `X-Loreloom: 1`.
- `cli.ts` usage: `tsx packages/server/src/cli.ts [bookDir]`.
  - The book dir defaults to `$LORELOOM_BOOK` or `~/Loreloom/my-book`, resolved to an absolute path and created if missing.
  - It picks the port (4317–4327), prints `Loreloom is open at http://127.0.0.1:<port>  (book: <dir>)`, and opens the browser (`open`/`xdg-open`/`start`) unless `--no-open` is passed.
